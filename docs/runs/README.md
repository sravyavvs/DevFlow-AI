# Run evidence

`scripts/demo.ps1` (Windows) and `scripts/demo.sh` (macOS/Linux) write the real output of each scenario here:
`<scenario>-pipeline.json`, `-events.json`, `-artifacts.json`, `-metrics.json`, and `-graph.json` (Mermaid).

Scenarios: `greenfield`, `brownfield`, `ambiguous`, `blocked-nfr`, `failure-recovery`.
